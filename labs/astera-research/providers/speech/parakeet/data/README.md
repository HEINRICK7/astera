# Dados do Parakeet Lab

Nenhum áudio, transcript ou caso clínico é distribuído neste repositório.

Para um experimento autorizado, mantenha os arquivos localmente em
`data/authorized/` e use uma manifestação fora do Git contendo, no mínimo:

- `case_id` pseudonimizado;
- autorização e origem do áudio;
- idioma, sample rate, canais, codec e duração;
- transcript de referência, quando houver;
- especialidade e critérios de anonimização;
- versão do dataset e checksum dos arquivos.

Não use áudio sintético para declarar certificação clínica. Dados públicos
também precisam ser verificados quanto à licença e adequação de uso.
