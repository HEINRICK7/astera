# Benchmark Results

| Campo | Valor |
|---|---|
| **Status** | Proposed |
| **Responsável** | Cognitive Validator |

## Objetivo

Consolidar resultados do Lab sem reduzir o modelo cognitivo a uma única métrica
ou a uma comparação de LLMs.

## Dimensões

| Dimensão | Medida |
|---|---|
| Fact Fidelity | Facts presentes, corretos e provenientes |
| Context Fidelity | Relações, timeline e atualizações preservadas |
| Reasoning Fidelity | Hipóteses suportadas e conflitos explícitos |
| Gap Quality | Lacunas reais e perguntas de alto valor |
| Knowledge Timing | Consulta justificada e versionada |
| Representation Fidelity | SOAP/FHIR derivado do Context |
| Information Loss | Conteúdo relevante ausente |
| Information Invention | Conteúdo sem origem no caso |
| Architecture Stability | Casos sem mudança estrutural necessária |

## Regra de interpretação

Benchmark Results descreve o comportamento do modelo cognitivo em um conjunto
de casos e versão da RFC. Não é ranking de LLM, garantia diagnóstica ou
aprovação clínica.
